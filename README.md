# Sabaq — MVP

Учёт для частных учебных центров Казахстана: преподаватель отмечает урок — Sabaq сам списывает занятие с абонемента, обновляет долг, сообщает родителю и начисляет зарплату.

**Открыть:** https://parzifalai.github.io/sabaq-mvp/

Роли в демо: владелец центра, преподаватель (мобильный экран), родитель (Kaspi QR — демо), публичный каталог свободных мест.

Что работает:
- отметка посещаемости → списание с абонемента, долги, уведомления, зарплата;
- правило абонемента (списывать ли пропуск без причины) с пересчётом остатков;
- оплата пакетом (Kaspi QR / наличные), напоминание родителю;
- расписание с проверкой конфликтов преподавателя и аудитории;
- зарплата из посещаемости + выгрузка CSV;
- импорт учеников из Excel (CSV);
- каталог свободных мест из живого расписания и заявки на пробный урок.

Без сервера: данные демонстрационные и хранятся в браузере (localStorage), пересоздаются раз в неделю или кнопкой «Сбросить демо-данные».
